## 一、六大核心 Insight（执行摘要与深度发现）

### Insight 1：零件底层架构——「面板五维」只是表象，「隐藏独立乘区」才是决定手感与TTK的真神

在游戏改枪界面中，玩家只能直观看到 **面板五维数值**（射程 `Attr2`、后坐力控制 `Attr3`、腰际射击精度 `Attr4`、操控速度 `Attr5`、据枪稳定性 `Attr6`）以及模糊的文字词条（如“水平后坐力控制提升”）。但通过提取全部 **577 个零件** 的底层引擎操作指令（`operations`），我们发现改枪系统中存在一套完全独立于面板五维之外的 **底层独立乘区（Hidden Engine Multipliers）**：

1. **消音器最大的认知差：`先进多口径消音器` (¥60,336) 全面碾压 `轻语战术消音器` (¥69,613)**
   - **表面面板**：`轻语战术消音器` 提供 `+18%射程初速、后坐+6、据枪+2、腰射-4、操控-5`，而 `先进多口径消音器` 面板后坐力控制为 `0`（仅 `+18%射程初速、腰射-4、操控-6`），导致交易行里 `轻语` 比 `先进` 贵近 1 万哈夫币。
   - **底层真相**：`先进多口径消音器` 在底层代码中直接挂载了与 **紫色毕业枪口 `堡垒水平补偿器` (¥46,412) 完全相同的三个独立乘区**：
     - `GRecoil_H (Mult_A) = -0.24`（**水平后坐力直接乘算 -24%**）
     - `GRecoil_HShake (Mult_C) = 0.76`（**水平后坐力晃动直接 -24%**）
     - `GGunkickH (Mult_C) = 0.88`（**开火枪身水平跳动 -12%**）
     - 同时，`先进多口径消音器` 的枪声传播距离乘数为 `ShotDistance = 0.5x`（**50%强消音**），而 `轻语战术消音器` 仅为 `0.7x`（**70%弱消音**）且没有任何独立后坐乘区！对于任何存在水平弹道散布的步枪/冲锋枪（如腾龙、K416、M7、M4A1、AKM、MP7），`先进多口径消音器` 相当于 **“免费白嫖了一个堡垒水平补偿器 + 18%射程初速 + 强效消音”**。

2. **为什么有些枪“抢鼠标”？决定压枪手感的核心参数是 `GGunkickRandom` 与 `GRecoil_Shake`**
   - 玩家常说的“枪口乱跳、抢鼠标”，在底层由四个独立参数控制：`GGunkickRandom`（随机枪身跳动）、`GGunkickSpring`（枪身回弹抖动）、`GRecoil_VShake`（垂直晃动）、`GRecoil_HShake`（水平晃动）。面板的 `后坐力控制` 对 `GGunkickRandom` 收益极低，只有特定零件能直接乘算削减它们：
     - **`兵锋新式握把`**（¥40,452，腾龙/QBZ95-1/QJB201专属后握把）：面板仅显示 `操控+2`，但底层直接赋予 **四项抖动全乘算 `×0.76`（全部直降 24%！）**，且零负面惩罚！这就是为什么腾龙装上兵锋握把后弹道立刻变乖。
     - **`新式腾龙稳固导气箍`**（¥36,623）：除面板 `后坐+4/据枪+3` 外，底层自带 **`水平后坐 -24% + 水平晃动 ×0.76 + 随机枪跳 ×0.76 + 回弹抖动 ×0.76`**。
     - **`FFC双流制退器`**（¥63,931）：面板 `后坐+6/据枪+3`，底层赋予 **四项晃动与随机枪跳全部 `×0.84`（-16%）**。
     - **`DTK制退器`**（¥31,997，俄系AK/KC17/SR-3M/PKM可用）：面板仅显示 `腰射+12`，底层却赋予 **四项晃动与随机枪跳全部 `×0.76`（-24%！）**，且 **不扣任何操控速度**！
     - **`CR棱镜阻手器`**（¥25,125，全枪通用前握把）与 **`枢机稳固枪托`**（¥22,042，AR通用枪托）：面板四维全是 `0`（零操控惩罚），底层直接赋予 **`垂直/水平晃动 ×0.76 (-24%) + 随机枪跳/回弹 ×0.88 (-12%)`**，是预算改枪的隐藏神器。

3. **突破操控阈值的独立开镜乘区（`GAiming_ADSTime`）与开镜移速加成（`GMovement_ADSSpeed`）**
   - 当面板 `操控速度` 堆高后，每点操控减少的开镜毫秒数会边际递减。但 **`幻影垂直握把`**（¥51,523）与 **`共振二代一体枪托`**（¥69,061）拥有 **`GAiming_ADSTime = -16%`**（**`EC通用前阻手`** 为 **`-12%`**），在面板换算完开镜时间后再直接乘算砍掉 16% 开镜耗时！
   - 开镜对枪时的螃蟹步移速（Peeker's Advantage）由隐藏参数 `GMovement_ADSSpeed` 决定：**`闪电导轨枪托`**（¥29,825）、**`精英轻型枪托`**（¥16,291）、**`M249精英骨架枪托`**（¥15,827）提供最高的 **`+0.12 m/s` 开镜移速**；而 `相位战斗前握把`、`MRGS镂空枪托`、`PKM泽宁特枪托`、`M14EBR枪托` 则隐藏了 **`-0.08 m/s` 开镜移速惩罚**（`KC17先进战斗枪托` 甚至高达 **`-0.12 m/s`**）。

4. **零件中的“暗坑”：面板好看但底层藏着巨大惩罚的零件**
   - **`AR轻薄握把片`**（¥46,581）：面板 `操控+2、据枪+4` 看似极品，但底层写死了 **`CameraSwayBeHitScale = +50%, GunSwayBeHitscale = +50%`**（**被命中时镜头与枪口受击上跳惩罚剧增 50%！**）。反观 **`SR-25主宰者护木`** 与 **`M700军规护木`** 则提供 **`-80%` 受击晃动减免**。
   - **`微型瞄具增高架`**（¥20,410）与 **`多用途战术增高架`**（¥23,985）：为了 `+2 操控速度` 装增高架，底层会偷偷附带 **`垂直晃动/水平晃动/随机枪跳/回弹抖动全部 ×1.04（恶化 +4%）`**！
   - **`折叠握把`**（¥10,801）：面板 `操控+2、据枪+5`，但底层附带 **`GRecoil_V = +12%`（垂直后坐力恶化 12%）**。
   - **`QCQ171新式高射速化枪机`**（¥28,903）：射速提升 11.1%（`763→848 RPM`），但除了面板 `后坐-4`，底层还附带 **`全向晃动与随机枪跳 ×1.16（恶化 +16%）`**。

### Insight 3：零件经济学与平替套利——「同属性不同命」的溢价陷阱与最优解
